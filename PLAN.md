# Plan: Multi-View-Consistent World Model via DMD Distillation on SPT

## Context — what we're building and why

SPT re-shoots a real video `v0` from a new camera/time to invent views `v1…vN`, but each
invented view commits to a *different* 3D world → stitched views don't line up. We fine-tune SPT
so all invented videos render **one shared world**, via **DMD distillation** (no multi-view GT
exists). This plan designs the **full method** — architecture changes + every loss term (D1–D4)
mapped to concrete code sites in `spacetimepilot/model/spacetimepilot.py`. SPT inference already
runs (Rung 0 done in another worktree).

**Hyunwoo's framing:** objective is `KL(q_θ(v2,v0) ‖ p(v2,v0))` between *joints*, same
distribution factorized differently. Teacher `p(v2,v0)=p(v2|v0)p(v0)` (we have it). Student
`q_θ(v2,v0)=∫dv1 q_θ(v2|v1,v0) p(v1|v0) p(v0)` — only `q_θ(v2|v1,v0)` is trained. Caveat:
score-of-sum ≠ sum-of-scores once diffused → marginal score must be *estimated*, not assembled.

---

## DECISION 0 — who conditions on what (this makes the method buildable)

This is the crux that decides whether the plan works. Reconciling the derivation with the
released model (which conditions a target on **exactly one** `source_video`, `:686`):

- **Teacher = the FROZEN released 1-source SPT, applied to pairs.** A teacher "arrow" is
  `∇_{v2}\log p(v2 | v1)`: feed `source=v1`, `target=v2`. We never feed it two sources, so the
  released weights stay in-distribution. `v0`'s influence enters because the **middles `v1` are
  drawn from `p(v1|v0)`** (themselves generated by the same frozen SPT from `v0`) **and** via the
  **crossing constraint** (each `v1` shares a (camera,world-time) point with `v2`, making `v1` a
  sufficient local summary of `v0`). Gap to the ideal 2-source `p(v2|v0,v1)` = an approximation
  to note in code (sits alongside the prior-vs-posterior gap, Q1).
- **Student `G_θ` = SPT with the N-source architecture extension (Rung A), TRAINABLE.** It
  generates `v2` conditioned on **2 sources `(v0,v1)`**. Mild OOD at first; the DMD loss
  fine-tunes it in (Hyunwoo: transformers extrapolate with minimal steps).
- **Fake-score net = a second extended (2-source) SPT, trainable**, mirroring the student so its
  score lives in the same conditioning space.

This matches Section 4's "teacher caps at 2 videos, student generates 3+, D4 is pairwise":
the **teacher is 1-source-on-pairs**; the **student is multi-source**.

## THE CRUX — velocity → score (flow matching)

SPT outputs **velocity** but every derivation needs a **score**. From `flow_match.py`
(`x_t=(1−σ)x_0+σε`, target `v=ε−x_0`):

```
x_0 = x_t − σ·v_pred ,   ε = x_t + (1−σ)·v_pred
score  s(x_t) = −( x_t + (1−σ)·v_pred ) / σ
⟹  DMD arrow  A = s_real − s_fake = −((1−σ)/σ)·( v_real − v_fake )   (x_t cancels)
```

`v_pred` is read from `model_fn_wan_video` output **sliced to target frames**
`[:,:,:tgt_latent_length]` (`:746`). Unit-test this conversion (known `x_0,ε` → analytic score)
before anything else — a sign error trains toward garbage silently.

## Rung A — N-source architecture (no new modules)

Extend three concat sites under one canonical `[tgt, src0(=v0), src1(=v1), …]` order:
1. **Fusion** `:730` `torch.cat([latents, source_latents], dim=2)` → cat N source latents
   (encode each source via VAE, `:687`).
2. **DiTBlock** `:313` (time) and `:321` (camera): cat N entries, same order.
3. **`model_fn_wan_video` dicts** `:792–796`: `{tgt, src}` → N entries.
Attention/RoPE/patchify/FFN/VAE/downsampler adapt automatically (sequence-length-agnostic). All
sources use the **same RoPE**; the **camera embedding** distinguishes views. Cost is quadratic in
`f·h·w` → keep teacher pairwise. No new modules; if views ever must be distinguished, add an
intra-video attention with **zero layer-scale** (off by default).

## Data — what a training example actually is (no GT v2)

DMD needs **no target-view ground truth**. A "dataset" item = **one real `v0` video + sampled
actions**: `a0` (its own camera/time), plus action trajectories `a1,a2` (camera+time) for the
counterfactual views, with `a1` **crossing-constrained** to `a2`. Reuse `single_video_test.py`
camera/time builders (`process_camera_trajectory`, `compute_pose_embedding`, time at 81-frame
granularity, cameras 12-num/frame `::4`). v0 sources: CamXTime eval videos (HF) or any real
clips at 81f@480×832, [−1,1]. (Rung 1's harness uses one real (source,target) pair only to test
the graph; Rung 2 onward uses v0 + sampled actions and *generates* v2.)

**Middle bank (the compute fix):** middles `v1` depend only on `v0`+action, **not** on student
params → **pre-generate a bank of K middles per v0 offline** (each = one frozen 1-source SPT
inference) and cache to scratch. Each training step samples K from the bank instead of running
50-step SPT inline. Without this, K×50-step generations per step make Rung 2 impractically slow.

## Rung 2 — DMD loop (D1 + D2). Three SPT instances.

Per step, on a v0 + sampled `(a1,a2)`:
1. **Pick / sample middles** `v1^(1..K)` from the bank (crossing-constrained to `a2`).
2. **Student generates `v2`** = SPT(2-source `(v0, v1^(1))`, target action `a2`) run **few-step**
   (e.g. 4 scheduler steps as in the `:727` loop but short). Gradients: backprop through the
   **last** step only first (DMD2-style, bounds memory); revisit full unroll if quality needs it.
   Call the clean output `x0_hat = G_θ(z)`.
3. **Sample a DMD noise level `t`**, noise `x0_hat → x_t` (`add_noise`).
4. **`s_real` (D2 marginal teacher):** for `k=1..K`, frozen SPT velocity `v_real^(k) =
   model_fn(source=v1^(k), target=x_t, a2)`, **with CFG** (`nega + cfg·(posi−nega)`, `:741`),
   run **sequentially under `no_grad`** to bound memory; convert each → score; **average**.
   ⚠️ Average is over the **prior** middles, not posterior `p(v1|x_t,v0)` → **biased**; crossing
   constraint is the safeguard (Q1). Principled alt (Hyunwoo's regression trick): a net regressing
   `v_real` from `(x_t,v0)` has conditional-mean optimum = unbiased posterior average.
5. **`s_fake`:** fake-score net velocity on `x_t` (2-source `(v0,v1^(1))`) → score.
6. **Student update (D1):** `loss_student = stop_grad((1−σ)/σ·(v_fake − v_real))ᵀ · x0_hat`
   (target frames only) → `backward()`, step student optimizer.
7. **Fake-net update:** separate optimizer; denoising-MSE (`training_target`) on `x0_hat` at a
   fresh `t`. It must keep chasing the moving student joint `q_θ(v2,v0)`.

**Build gates:** (2a) **K=1** first = vanilla 2-source DMD distillation — verify student doesn't
diverge, fake-net loss decreases, generated v2 *sharpens* over steps (arrow sign correct).
(2b) **K>1** = the contribution — verify `s_real` variance drops with K and cross-view geometry
agrees better.

## Rung 3 — Stitching term (D3): anti-blur force

Consistency alone collapses to gray blur (two blurs agree). Take **one frame per generated video**
at the shared world-time → strip `x = W v` (`W` = disjoint binary selection, one 1 per kept
pixel). Disjoint ⇒ `WWᵀ=I` ⇒ noising commutes with slicing ⇒ `s_x(x_t)=W·s_v(v_t)`: **reuse the
joint score, no new net.** Demand the strip look like a real single video (sharp + temporally
smooth) via the same DMD/DPS machinery sliced by `W`; add its score term into step 6. ⚠️ `WWᵀ=I`
needs genuinely disjoint frames / high-noise regime (Q2). **Ablation gate:** remove stitching →
blur must return (proves it's the anti-blur force).

---

## Rung 4 — Scaling past two views (D4): pairwise windows

Student generates N; teacher is pairwise. Enforce D1/D2/D3 on **every overlapping window**
(123,234,345…), sum per-window losses. **Bet (not theorem):** overlapping-pairwise ⇒ global
consistency by transitivity, anchored by window overlap + crossing constraints. **Watch drift**
(slack accumulating so distant views disagree while neighbors pass) — measure cross-view geometry
error vs. chain distance. Self-Forcing is the precedent for student-N/teacher-2 length mismatch.

## Build order & verification (gate each before next)

1. **Crux unit test** — velocity→score on known inputs matches analytic score.
2. **Rung A + Rung 1** — extended forward runs; harness gives finite loss + correct grad mask.
3. **Middle-bank generation** — cache K middles per v0; eyeball crossing constraint.
4. **Rung 2a (K=1)** — student sharpens, fake-net converges, no divergence.
5. **Rung 2b (K>1)** — `s_real` variance ↓ with K; consistency ↑.
6. **Rung 3** — strip sharp; ablation restores blur.
7. **Rung 4** — N-view; drift measured along the chain.

All heavy runs on a GPU node via `srun/sbatch`, env
`/orcd/scratch/orcd/014/akshatat/conda_envs/counterfactual` (torch 2.4.1+cu121); never login node.

*unfrozen subset* only (student, fake-net) + activations w/ grad-checkpointing. Teacher K-evals
looped sequentially under `no_grad`. 2-video seq len = 42·30·52 ≈ 65.5k tokens → quadratic
attention is the real sink; keep B=1, monitor with `nvidia-smi`. Wan2.1 base is on scratch;
**SPT checkpoint still needs downloading** (`hf download zhening/SpaceTimePilot
